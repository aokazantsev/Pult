# Опыты с хуками Claude Code

Заглушки для проверки фактов платформы (`docs/FACTS.md`, итоги этапа 1). Пишут каждое событие в журнал JSON Lines,
по настройке ждут, отвечают и шлют пульс, чтобы было видно, когда агент убил процесс.

| Файл | Что делает |
|---|---|
| `stub.py` | хук-скрипт: вход события и окружение `CLAUDE*` — в журнал; поведение — из аргументов или из `control.json` по имени события (`sleep`, `heartbeat`, `stdout`, `answer_file`, `block_times`) |
| `make_lab.py` | создаёт папку `lab/` с `.claude/settings.json`: все события на `stub.py`, `PermissionRequest` с таймаутом 60 с, `Stop` — 120 с |
| `http_server.py` | приёмник HTTP-хука на loopback: пишет заголовки и тело, отвечает заданным JSON с задержкой |
| `show.py` | журнал в читаемом виде: события, ответы, пульс процессов |

Порядок:

1. `python make_lab.py` — создаёт `lab/` (в git не попадает: пути к Python и журналу локальные).
2. Открыть тред Claude Code в папке `lab/` с режимом разрешений «спрашивать».
3. Менять поведение хуков правкой `lab/control.json` без перезапуска треда, например
   `{"Stop": {"answer_file": "<путь>/stop_answer.json", "answer_timeout": 100, "heartbeat": true}}` — хук окончания
   хода ждёт файл и отдаёт его содержимое агенту.
4. `python show.py lab/hooks.jsonl [с какой строки]`.

Ответ хука с кириллицей пишется в stdout байтами UTF-8: иначе Python на Windows отдаёт CP1251.
