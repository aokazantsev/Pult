# Pult server

Реле между ПК и телефоном: поток SSE и `POST` для обеих сторон, очередь на получателя на диске, служебный сигнал
«поток телефона открыт / закрыт» для ПК, порог живости. Python 3.10+, только стандартная библиотека. Формат сообщений —
[`protocol/README.md`](../protocol/README.md).

## Запуск

```bash
python3 -m pult_relay add-pair --id dev
python3 -m pult_relay run
```

`add-pair` печатает токены ПК и телефона и записывает их в `data/pairs.json`; без пар `run` создаёт пару сам. Windows —
`run.cmd`, Linux — `run.sh`.

| Переменная | По умолчанию | |
|---|---|---|
| `PULT_DATA` | `data` | каталог состояния (`pairs.json`, `state.json`) |
| `PULT_HOST`, `PULT_PORT` | `127.0.0.1`, `8082` | адрес |
| `PULT_MAX_TTL` | `900` | верхняя граница срока жизни конверта, с |
| `PULT_MAX_QUEUE` | `200` | очередь на получателя |
| `PULT_MAX_ENVELOPE` | `65536` | размер конверта, байт |
| `PULT_KEEPALIVE`, `PULT_LIVENESS` | `15`, `45` | комментарий в потоке; порог «без признаков жизни», с |

Состояние пишется атомарно (временный файл, `fsync`, `os.replace`) при каждом изменении очереди и переживает перезапуск.
После перезапуска все потоки закрыты, клиенты переподключаются сами.

## Тесты

```bash
python3 -m unittest discover -s tests -t .
```

Включая перезапуск процесса: очередь и память идентификаторов целы.
