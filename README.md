# Pult

Пульт для ИИ-агентов на ПК: телефон показывает, что делают треды агента (Claude Code и другие), и позволяет
ответить на запрос разрешения, вопрос с вариантами или продолжить тред текстом, не подходя к компьютеру.

Независимый проект, не связан с Anthropic.

## Состояние

Идёт сквозной прототип: хук агента → программа на ПК → сервер → телефон → ответ. Протокол 2 (ключи, сопряжение по QR,
шифрование, подпись запросов) реализован в server, desktop и mobile; дальше — статусы, лента и снимок (этап 3).

## Как устроено

- **desktop** — фоновая программа в трее на ПК и хуки агента. Управление только через хуки: без захвата экрана и
  имитации кликов.
- **server** — реле между ПК и телефоном. Видит только зашифрованные сообщения, разворачивается кем угодно одной
  командой.
- **mobile** — приложение на Kotlin Multiplatform и Compose Multiplatform, Android. События идут потоком SSE, пока
  приложение открыто; уведомлений нет.
- **protocol** — спецификация сообщений и эталонные векторы криптографии.

ПК и телефон связываются по QR: ПК показывает QR с одноразовым секретом, которого сервер не видит, телефон
сканирует его, заверяет свои ключи этим секретом, а ПК проверяет заверение. Ключи P-256 не покидают устройства, каждый
запрос к серверу подписан, сообщения шифруются сквозным образом (подробности — [`protocol/CRYPTO.md`](protocol/CRYPTO.md)).

## Сборка

- **desktop** (Windows, .NET Framework 4.8, штатный `csc.exe`, без SDK): из папки `desktop` — `build.cmd nostart`
  собирает `Pult.exe`; без `nostart` собранная программа ещё и запускается. Журнал и настройки — в
  `%LOCALAPPDATA%\Pult` (`log.txt`, `settings.txt`, порт приёма хуков — `hook_port`, по умолчанию 47652).
- **mobile** (Android, JDK 17 и Android SDK, путь к SDK — `sdk.dir` в `mobile\local.properties`, слеши прямые): из папки
  `mobile` — `./gradlew assembleStandardDebug`, APK — `app/build/outputs/apk/standard/debug/app-standard-debug.apk`; пакет
  отладочной сборки — `ru.aokazantsev.pult.debug`. Отладочная сборка работает и на телефоне без блокировки экрана: вход
  без запроса биометрии или PIN; с блокировкой вход обычный. Единственный флейвор `standard` нужен варианту `standardDebug`: так его
  принимает `slots.py apk --variant standardDebug` (кладёт APK в папку артефактов проекта). Отладочная сборка
  сопрягается и без камеры, командами adb — [`docs/ADB-PAIRING.md`](docs/ADB-PAIRING.md).
